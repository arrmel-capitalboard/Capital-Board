Animations des prix — tableau « Mes titres »

Six façons de signaler qu'un prix vient de bouger au refresh. Chaque carte contient un vrai tableau avec les quatre lignes du portefeuille ; « Refresh » tire de nouveaux prix (±1,5 %) et recalcule valeur, +/- value et perf. jour, comme le ferait renderPortfolio(). Les hausses sont en vert, les baisses en rouge.

Point d'implémentation commun : renderPortfolio() reconstruit tout le <tbody>, donc les anciennes valeurs disparaissent avant qu'on puisse les comparer. Il faut les relever avant le re-render (une Map ticker → prix), puis appliquer l'animation après. Les variantes 2 et 3 vont plus loin : elles ont besoin que la cellule survive au refresh, donc de mettre à jour les cellules en place plutôt que de régénérer le HTML.

1 Flash de fond recommandé

La cellule s'illumine 900 ms puis retombe. C'est la convention des terminaux boursiers : verte si le prix monte, rouge s'il baisse. Lecture immédiate, aucun déplacement de texte.

CSS + JS 
/* css/style.css */
@keyframes f-up {
  0%   { background: rgba(0,224,158,.22);
         box-shadow: inset 0 0 0 1px rgba(0,224,158,.38); }
  100% { background: transparent;
         box-shadow: inset 0 0 0 1px transparent; }
}
@keyframes f-down { /* idem en --negative */ }
#portfolio-tbody td.fx-up   { animation: f-up   .9s cubic-bezier(.2,.8,.2,1);
                              border-radius: 6px; }
#portfolio-tbody td.fx-down { animation: f-down .9s cubic-bezier(.2,.8,.2,1);
                              border-radius: 6px; }

// js/app.js — relever AVANT le re-render, animer APRÈS
function snapshotPrices() {
  const m = new Map();
  document.querySelectorAll('#portfolio-tbody tr[data-tk]').forEach(tr => {
    m.set(tr.dataset.tk, +tr.querySelector('.c-px').dataset.raw);
  });
  return m;
}
function flashChanges(before) {
  document.querySelectorAll('#portfolio-tbody tr[data-tk]').forEach(tr => {
    const old = before.get(tr.dataset.tk);
    if (old === undefined) return;              // ligne nouvelle
    ['.c-px', '.c-val', '.c-plus', '.c-day'].forEach(sel => {
      const cell = tr.querySelector(sel);
      const now  = +cell.dataset.raw;
      if (!cell || now === old) return;
      const cls = now > old ? 'fx-up' : 'fx-down';
      cell.classList.add(cls);
      cell.addEventListener('animationend',
        () => cell.classList.remove(cls), { once: true });
    });
  });
}

2 Défilement vertical

L'ancien chiffre sort par le haut, le nouveau entre par le bas — l'inverse quand ça baisse. Le sens du mouvement dit déjà la direction, la couleur ne fait que confirmer. Effet « cotation en direct ».

HTML + CSS + JS 
<!-- chaque valeur animable est enveloppée -->
<td class="c-px"><span class="roll"><span class="rl">97,96 €</span></span></td>

.roll { display:inline-block; overflow:hidden;
        vertical-align:bottom; position:relative; }
.roll .rl { display:block; }
.roll .rl.enter { position:absolute; inset:0 0 auto 0; text-align:right; }
@keyframes r-out-up { to { transform:translateY(-100%); opacity:0; } }
@keyframes r-in-up  { from { transform:translateY(100%); opacity:0; }
                      to   { transform:none; opacity:1; } }

// js/app.js — remplace le texte par un glissement
function rollTo(cell, text, up) {
  const box = cell.querySelector('.roll');
  const cur = box.querySelector('.rl:not(.enter)');
  const nxt = document.createElement('span');
  nxt.className = 'rl enter ' + (up ? 'in-up' : 'in-down');
  nxt.textContent = text;
  box.style.height = cur.offsetHeight + 'px';   // fige la hauteur
  box.appendChild(nxt);
  cur.classList.add(up ? 'out-up' : 'out-down');
  nxt.addEventListener('animationend', () => {
    cur.remove();
    nxt.classList.remove('enter', 'in-up', 'in-down');
    box.style.height = '';
  }, { once: true });
}

3 Comptage progressif

Le nombre défile de l'ancienne à la nouvelle valeur en 700 ms, teinté pendant la transition. Même principe que countUp() déjà utilisé pour les cartes de stats — cohérent avec le haut de la page.

JS 
// js/app.js — countUp() existe déjà, on l'applique aux cellules
function countCell(cell, from, to, fmt, ms) {
  ms = ms || 700;
  const t0 = performance.now();
  cell.classList.add(to > from ? 'tint-up' : 'tint-down');
  (function step(now) {
    const t = Math.min((now - t0) / ms, 1);
    const e = 1 - Math.pow(1 - t, 3);            // easeOutCubic
    cell.textContent = fmt(from + (to - from) * e);
    if (t < 1) requestAnimationFrame(step);
    else cell.dataset.raw = to;
  })(t0);
  cell.addEventListener('animationend',
    () => cell.classList.remove('tint-up', 'tint-down'), { once: true });
}

4 Soulignement balayé discret

Un trait fin se déploie sous la valeur puis s'efface, sans toucher au fond ni à la couleur du texte. La variante la plus sobre : visible du coin de l'œil, jamais gênante à la lecture.

  55%  { transform: scaleX(1); opacity: 1; }
  100% { transform: scaleX(1); opacity: 0; }
}

5 Delta flottant

L'écart exact (+0,42 €) apparaît au-dessus de la cellule, monte et s'efface. Seule variante qui donne le chiffre du mouvement, pas seulement son sens. Réservée aux colonnes en euros.

CSS + JS 
.delta {
  position: absolute; right: 5px; top: 2px; pointer-events: none;
  font-family: var(--mono); font-size: 9.5px; font-weight: 700;
  white-space: nowrap;
  animation: d-float 1.15s cubic-bezier(.25,.8,.3,1) forwards;
}
.delta.up { color: var(--positive); } .delta.down { color: var(--negative); }
@keyframes d-float {
  0%   { opacity:0; transform:translateY(6px); }
  22%  { opacity:1; transform:translateY(-3px); }
  70%  { opacity:1; transform:translateY(-9px); }
  100% { opacity:0; transform:translateY(-15px); }
}

// js/app.js
function showDelta(cell, diff) {
  const el = document.createElement('span');
  el.className = 'delta ' + (diff > 0 ? 'up' : 'down');
  el.textContent = (diff > 0 ? '+' : '') + fmtEur(diff);
  cell.appendChild(el);
  el.addEventListener('animationend', () => el.remove(), { once: true });
}

6 Halo + respiration

Le chiffre grossit de 9 %, s'allume d'un halo coloré, puis revient à sa taille et à sa couleur normales. Le plus démonstratif — pertinent si le refresh est rare, trop présent s'il est fréquent.

CSS 
#portfolio-tbody td { transform-origin: right center; }
@keyframes g-up {
  0%   { color: var(--positive);
         text-shadow: 0 0 12px rgba(0,224,158,.75); transform: scale(1.09); }
  45%  { color: var(--positive);
         text-shadow: 0 0 6px rgba(0,224,158,.4);   transform: scale(1); }
  100% { color: var(--text); text-shadow: none; transform: scale(1); }
}
@keyframes g-down { /* idem en --negative */ }
td.fx-up   { animation: g-up   .95s cubic-bezier(.2,.8,.2,1); }
td.fx-down { animation: g-down .95s cubic-bezier(.2,.8,.2,1); }

À noter : la colonne Perf. jour peut changer de signe. Sa couleur de base (vert/rouge) est portée par la valeur elle-même, pas par l'animation — les deux se superposent, d'où le retour à la couleur de la nouvelle valeur en fin d'animation plutôt qu'au gris de base.
