Animations de re-rendu — graphique & tableau

Ce qui se déclenche aujourd'hui à chaque refreshAll() / changement de période : le graphique rejoue son animation d'entrée complète (duration: 1200, easeOutQuart — js/app.js:6943) et les 4 lignes du tableau re-glissent depuis la gauche (.stagger-row + animationDelay 40 ms × index — js/app.js:8305, css/style.css:1703).

Le vrai problème n'est pas l'easing, c'est qu'on ne distingue pas premier rendu et re-rendu. Une animation d'entrée est justifiée quand le contenu apparaît. Au refresh, les données bougent de 0,3 % : tout remettre à zéro pour re-jouer 1,2 s d'animation donne l'impression que la page se recharge. Les variantes ci-dessous sont donc étiquetées premier rendu ou re-rendu.

1 Morph des valeurs re-rendu

On n'anime que l'axe Y, et seulement l'écart entre ancienne et nouvelle valeur. La courbe se déforme vers son nouvel état au lieu de renaître. C'est le comportement attendu d'un rafraîchissement de prix.

Config 
options: {
  animation: { duration: 500, easing: 'easeInOutCubic' },
  animations: {
    y: { duration: 500, easing: 'easeInOutCubic' },
    x: false,          // pas de balayage horizontal
    radius: false      // les points ne re-poppent pas
  },
  transitions: {
    // première apparition : on garde un déploiement doux
    show: { animations: { y: { from: ctx => ctx.chart.scales.y.getPixelForValue(0) } } }
  },
  …
}

2 Tracé progressif premier rendu

La courbe se dessine de gauche à droite, comme un tracé qui se déroule dans le temps — le geste correspond à la lecture d'un historique. Réservé au premier affichage ; au refresh on bascule sur la variante 1.

Config 
// Chaque point entre en scène décalé selon son index :
// le tracé se déroule de gauche à droite.
const total = values.length;
options: {
  animation: {
    duration: 900, easing: 'easeOutQuart',
    // 900ms répartis sur toute la série
    delay: (ctx) => ctx.type === 'data' && ctx.mode === 'default'
      ? ctx.dataIndex * (700 / total) : 0
  },
  animations: {
    x: { duration: 0 },
    y: { duration: 220, from: (ctx) =>
           ctx.chart.scales.y.getPixelForValue(ctx.chart.scales.y.min) }
  },
  …
}

3 Fondu du conteneur re-rendu

Zéro animation dans le canvas : les données sont posées instantanément, seul le bloc fait un fondu de 220 ms en CSS. Le plus sobre et le plus rapide — rien ne bouge, la lecture des chiffres n'est jamais brouillée.

1 Flash des cellules modifiées re-rendu

Aucune ligne ne bouge. Seules les cellules dont la valeur a réellement changé s'illuminent 900 ms, en vert si le prix monte, en rouge s'il baisse. L'œil est envoyé exactement là où l'information est neuve.

CSS + JS 
/* css/style.css */
@keyframes cell-flash-up {
  0%   { background: rgba(0,224,158,.20);
         box-shadow: inset 0 0 0 1px rgba(0,224,158,.34); }
  100% { background: transparent;
         box-shadow: inset 0 0 0 1px transparent; }
}
@keyframes cell-flash-down { /* idem en --negative */ }
td.flash.up   { animation: cell-flash-up   .9s cubic-bezier(.2,.8,.2,1);
                border-radius: 6px; }
td.flash.down { animation: cell-flash-down .9s cubic-bezier(.2,.8,.2,1);
                border-radius: 6px; }

// js/app.js — comparer avant/après plutôt que tout re-animer
const before = new Map([...rows].map(tr =>
  [tr.dataset.ticker, tr.querySelector('.px').textContent]));
renderPortfolio();
document.querySelectorAll('#portfolio-tbody tr').forEach(tr => {
  const cell = tr.querySelector('.px');
  const old  = before.get(tr.dataset.ticker);
  if (old === undefined || old === cell.textContent) return;
  const up = parseFloat(cell.dataset.raw) > parseFloat(old);
  cell.classList.add('flash', up ? 'up' : 'down');
  cell.addEventListener('animationend',
    () => cell.classList.remove('flash','up','down'), { once: true });
});

3 Stagger vertical court premier rendu

Même principe qu'aujourd'hui mais sur l'axe vertical (7 px), plus rapide (18 ms de décalage) et plafonné à 12 lignes pour que la dernière n'attende jamais. À réserver au premier affichage de la page.

CSS + JS 
@keyframes row-up {
  from { opacity:0; transform: translateY(7px); }
  to   { opacity:1; transform: none; }
}
.stagger-row { animation: row-up .34s cubic-bezier(.16,1,.3,1) both; }

// js/app.js — plafond : la 13e ligne n'attend pas plus que la 12e
tr.style.animationDelay = (Math.min(i, 12) * 0.018) + 's';
