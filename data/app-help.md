Guide d'utilisation de l'application Capital Board (aide destinée aux utilisateurs).

## Ajouter une action / un titre à son portefeuille

Pour ajouter une action (par exemple LVMH, Apple, TotalEnergies) à votre portefeuille :

1. Allez sur la page **Portefeuille** (c'est la page d'accueil de l'application après connexion).
2. Dans la section **« Mes titres »**, cliquez sur le bouton **« ＋ Ajouter une ligne »** (en haut à droite du tableau).
3. Une fenêtre **« Ajouter une action »** s'ouvre.
4. Dans le champ de recherche, tapez simplement le **nom de l'action** (ex : « LVMH »). Une liste de résultats apparaît : sélectionnez la bonne. Vous n'avez pas besoin de connaître le code boursier (ticker), la recherche le trouve pour vous.
5. Saisissez la **quantité** d'actions que vous détenez.
6. Saisissez le **prix d'achat** (prix unitaire).
7. Optionnellement, indiquez la **date d'achat**.
8. Validez pour ajouter la ligne à votre portefeuille.

## Importer plusieurs positions d'un coup (CSV)

Sur la page **Portefeuille**, section **« Mes titres »**, cliquez sur **« Importer CSV »** pour importer plusieurs lignes depuis un fichier CSV (utile pour transférer un export de votre courtier). Un bouton **« CSV »** permet aussi d'exporter votre portefeuille.

## Modifier ou supprimer une ligne

Dans le tableau **« Mes titres »**, chaque ligne dispose d'actions permettant de la modifier ou de la supprimer. Vous pouvez aussi filtrer les titres, les trier, et les réorganiser.

## Les pages de l'application

- **Portefeuille** : vos titres, leur valeur, performance et plus/moins-values. Page principale.
- **Activité** : toutes vos opérations (achats, ventes, dividendes, attributions, versements).
- **Dividendes** : historique des versements de dividendes par action détenue.
- **Watchlist** : suivez des actions sans les posséder. Ajoutez-en via **« ＋ Ajouter »**.
- **Performance** : rendement TWR annuel (nécessite un CSV de votre courtier).
- **Benchmark** : compare votre PEA aux grands indices, en base 100.
- **Projections** : simulation patrimoniale long terme avec intérêts composés.
- **Calendrier des résultats (Earnings)** : publications de résultats à venir ; abonnez-vous pour être notifié.
- **Actualités** : l'essentiel des marchés.
- **Contenus favoris** : dernières publications des comptes suivis.
- **Récap** : performance de votre PEA, en synthèse quotidienne et hebdomadaire.
- **Alertes prix** : recevez une notification quand un cours atteint le seuil que vous fixez.
- **Notifications** : réglages des notifications push et du récap quotidien.
- **Support** : discussion directe avec l'équipe Capital Board.

## Alertes de prix

Sur la page **Alertes prix**, définissez un seuil pour une action : vous recevez une notification dès que le cours l'atteint.

## Support

Pour toute question non couverte ici, utilisez la page **Support** de l'application pour contacter directement l'équipe Capital Board.
