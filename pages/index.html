Sécurité

Vos données, votre contrôle

Chaque couche de protection détaillée. Aucune zone grise.

Chiffrement TLS 1.3

Toutes les communications client ↔ serveur chiffrées. Aucune donnée transmise en clair sur le réseau.

Chiffrement au repos

Données Firestore chiffrées par Google côté serveur (AES-256). Backups automatiques chiffrés également.

Hébergement Europe

Région Firestore europe-west1 (Belgique). Conformité RGPD, aucun transfert hors UE.

Aucun mot de passe stocké

Authentification Firebase Auth (Google). Hashing bcrypt côté serveur Google. Aucun accès direct aux credentials.

Code 100% auditable

Repo GitHub public. Aucun binaire opaque, aucune extension propriétaire. Vous lisez ce qui tourne dans votre navigateur.

Règles Firestore strictes

Chaque document n'est lisible que par son propriétaire authentifié (request.auth.uid == resource.data.uid).

Conformité RGPD

Export et suppression de compte en 1 clic. Aucun cookie tiers, aucun tracker analytique sans consentement.

Zéro agrégation bancaire

Aucune connexion à votre banque. Pas d'intermédiaire Bridge/Powens/Tink. Vos identifiants bancaires ne quittent jamais votre banque.

FAQ

Questions fréquentes

C'est vraiment 100% gratuit, sans piège ?
Oui. Pas de freemium, pas de fonctionnalités payantes, pas d'abonnement caché. Le projet est open source et hébergé sur GitHub Pages (gratuit). Les seuls coûts (Firebase, API IA) sont à ma charge tant qu'ils restent dans les quotas gratuits.
Où sont stockées mes données exactement ?
Sur Firestore (Google Cloud), région europe-west1 en Belgique. Chiffrées au repos (AES-256) et en transit (TLS 1.3). Aucun transfert hors UE. Vous pouvez exporter ou supprimer toutes vos données depuis votre profil.
Comment importer mes transactions depuis ma banque ?
Deux options : saisie manuelle (rapide pour quelques transactions) ou import CSV (compatible Bourse Direct, Boursorama, Fortuneo et la plupart des courtiers PEA). Le parser détecte automatiquement le format.
Quelle différence avec Finary ou Trade Republic ?
Finary agrège vos comptes bancaires (modèle freemium, données revendues anonymisées). Trade Republic est un courtier avec son propre dashboard. Capital Board ne touche pas à vos comptes : vous gardez le contrôle complet, sans dépendance bancaire, et tout le code est public.
Est-ce que je risque de perdre mes données ?
Firestore fait des backups automatiques côté Google. Vous pouvez aussi exporter manuellement tout votre portefeuille au format JSON à tout moment. Si je décide d'arrêter le projet, je préviendrai à l'avance pour que chacun puisse récupérer ses données.
L'analyse IA est-elle fiable pour prendre des décisions ?
Non. L'IA fournit une synthèse de votre portefeuille et des actualités liées à vos titres, à titre informatif uniquement. Ce n'est pas un conseil en investissement. Les décisions restent les vôtres.
Mobile : ça marche bien ?
Interface responsive. Notifications push fonctionnent sur Android et iOS 16.4+ (installation en PWA requise sur iPhone : Partager → Sur l'écran d'accueil).
Je peux contribuer au code ?
Avec plaisir. PRs bienvenues sur GitHub. Les issues taggées good-first-issue sont un bon point d'entrée. Suggestions de features aussi recevables via les issues.
